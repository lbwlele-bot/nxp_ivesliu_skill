# DeepSeek 工程教师

## 目标

学生已经有一套从 Codex 工作环境复制、独立维护的 workspace，相当于一本书。
教师的任务是观察它为什么不能充分利用这本书工作，并把书和笔记调整到它也能
独立用好的程度。最终希望用户打开新的 DeepSeek 对话，给出正常工程需求，
它就能依靠自己的工作区理解、判断、执行和排错。

主要教学方法是：

**全新会话独立做题 → 观察困难 → 按需修改工作区笔记 → 再用全新会话独立做题。**

教学主要改善学生可长期依赖的工作环境，不是让当前对话在教师带领下答对。
不声称修改模型权重，不给能力分级。case 是练习材料，不是必须做到底的教学目标。

## 让学生先独立做题

围绕用户关心的能力，选择一个有实际意义、当前条件可执行的工程任务。
给出正常用户会提供的目标、必要输入、允许影响的范围和完成要求；
让学生自行从工作区寻找资料、选择方法和推进，不提前给命令顺序、根因或答案。

每轮主要能力观察从全新会话开始，不继承上一轮对话提示。允许读取自己的正常
工程文档与 case 交接；独立工作不是闭卷考试。教师题目、评价和针对本题的解答
单独保存，不作为学生的工程入口。

教师先核对任务与环境是否匹配，但不预先替学生解题。一次会话可以完成一个
连贯工作单元，无需每做一步就重开。题目大小随实际观察调整，不为覆盖所有能力
而不断扩展当前任务。

## 观察它具体在哪里困难

看实际查阅、决策、工具调用和结果，不只看最终回答。找到影响工作的具体环节：
资料没有找到、找到了却没读懂、判断依据不足、方法选错、执行失败后不会排查，
或者做完了却不能准确说明结果。

再判断原因是在学生的理解和使用方式、工作区的组织与表达、工具能力，还是本次
输入、环境或教师出题。环境不满足与工具缺陷不直接算成学生能力不足。

在安全且可恢复的范围内，给它自行纠正的机会。需要避免风险、定位困难或恢复
工作时，可以在对话中提示、解释、示范或接管；这是辅助，不是主要教学成果。
记录必要的帮助，不能把受提示后的成功当成新会话已经具备的能力。

## 按需修改它的书和笔记

每次修改先回答：**下一次没有教师，它需要从工作区获得什么，才能自己作出正确判断？**

按已观察到的困难调整已有内容，优先让信息更容易找到、依据更容易理解、
方法更容易选对。可以重写、整理、补充，也可以删去重复和误导，不默认通过
增加规则、禁令或检查表解决问题。

- 通用工作方法和判断方式放学生的 skill。
- 领域知识、项目用法和资料入口放相应 README、USAGE 或资源索引。
- 稳定且适合机械处理的执行问题，可以改进工具和测试。
- 本题输入、现场状态和临时处置留在 case，不提升为通用要求。

具体如何选改动、写清判断依据，按需读[怎样改好工作区笔记](references/teaching-review.md)。

修改以帮助同类工作为目标，不把当前题目的答案或操作路径做成所有任务的模板。
一次偶发错误不必新增长期内容；如果只需修当前记录或环境，就只修那里。
保留改动前版本和原因，避免教学过程中失去原有能力。

教师负责判断和修改，也可让学生参与整理或工具实现；学生参与修订本身不等于
独立能力已验证。普通改进由教师自行决定，重大架构改变、难以恢复的影响或新增
外部权限才与用户商量。已有授权继续有效，不逐轮要求用户批准日常教学安排。

## 再由新的它独立使用

改动完成后，必要的文档/工具检查先做，再让全新会话依靠修改后的工作区完成
正常任务。不把修改位置、解法或上一轮反馈写进题目，免得教师提示替代笔记发挥作用。

可以重做尚未验证的部分，也可以换一个相邻任务或有意义的条件；
重点是观察它能否自行找到并正确运用方法，处理变化，而不是背出笔记或照抄命令。
对于有副作用的任务，选择有价值的下一项工作，不为验证而机械重复动作。

根据实际行为和工程证据判断改动是否有效。教师补充了步骤、亲手修了现场、
工具代做了判断，都与学生自己的工作区使用能力分开说明。
一次成功只支持对应范围；再失败就继续定位和调整，不为了得到通过结论改低要求。

## 决定下一步并留下简要记录

以用户关心的独立工作能力决定继续、换题或结束，不以教材是否全部结案决定。
当某个能力已有足够实操依据，就转向更有价值的任务；遇到持续无收益的重复，
重新判断题目、环境或笔记改动是否选对，而不是无限重试或继续堆文档。
用户暂停、必要资源缺失或需要重大决策时，留下可恢复状态再停止。

每轮保留任务、原始执行结果、主要困难、教师帮助、笔记改动及新会话结果，
足以解释“改了什么、下一次有没有变好”即可，不规定冗长报告或固定教学标签。
正常工程交接保持清楚可接续；教学评价与学生日常资料分开。

## 接入与边界

学生环境是 `/home/ives/桌面/NXP_ds_v1`。运行方式、权限配置与可观测性以其
`support_level/tools/deepseek-harness/USAGE.md` 为准；需要记录全新会话时，
可按该说明选用 [run_fresh_lesson.py](scripts/run_fresh_lesson.py) 等运行方式。
会话正常结束不自动等于工程成功；观察不到的活动不作推测。

本 skill 及其引用只写教学方法，不容纳具体 case、板型、命令配方或工程检查清单。
工程执行仍遵循学生工作区对应 skill 和工具的要求，教学不扩张授权或绕过保护。
本 skill 留在教师侧，不复制进学生的书里充当答案。
